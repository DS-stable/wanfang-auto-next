# 万方课程自动连播

用于万方科研诚信培训课程页的 **Chrome / Microsoft Edge 扩展**，当前版本 **1.4.0**。

视频播放结束后，等待设定时间，切换下一节并尝试播放；也可随时使用“下一视频”按钮主动换课。新增“定时续播”按钮，可在暂停 5 秒后恢复播放，或选择“∞”保持原状。

## 下载与安装

1. 下载 [wanfang-auto-next-v1.4.0.zip](https://github.com/DS-stable/wanfang-auto-next/raw/refs/heads/main/dist/wanfang-auto-next-v1.4.0.zip) 并解压，版本更新见 [Releases](https://github.com/DS-stable/wanfang-auto-next/releases)。也可以点击仓库的 **Code → Download ZIP**，解压后使用仓库根目录。
2. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的文件夹**。
4. 打开万方课程学习页并刷新，右下角会出现“万方 · 自动连播 1.4.0”面板。

安装和使用扩展不需要 Node.js、npm 或编译步骤。保留安装文件夹，浏览器需要继续读取其中的文件。

## 使用

- 正常登录万方并打开 `/e-training/quality/courselearn` 学习页，手动播放当前节一次。
- ∞ 模式下，视频自然结束后默认等待 **5 秒**再切换，支持 **3 / 5 / 10 秒**。开启暂停后 5 秒续播时，视频暂停及结束均按固定 **5 秒**处理，不再叠加切换等待。
- 视频页的 **“下一视频”**可主动切换到左侧目录中的下一段视频，并尝试播放；关闭自动连播时也可手动使用。
- 随堂测验由使用者手动作答并提交。页面显示提交结果后，插件会倒计时并从目录继续下一视频；测验和文档页也提供 **“继续下一视频”**按钮。
- 浏览器若拦截自动播放，可点击面板上的 **“播放当前节”**。
- **“定时续播：∞”**是默认状态，保持原来的暂停行为。点击按钮切到 **“定时续播：5 秒”**后，每次暂停会倒计时 5 秒，再尝试继续当前视频；再次点击切回 ∞。手动暂停也会触发，可点“取消本次续播”，或切回 ∞ 保持暂停。
- 定时续播可独立恢复当前视频；进入下一节仍由自动连播开关控制。5 秒模式覆盖手动暂停、刷新、后台、播放器重建、加载未完成、拖动定位、视频错误、弹窗及播放启动中的暂停。拖动、元数据加载或源地址从空变为可用都不会重置原来的截止时间；真正切换到其他视频时使用新的完整 5 秒。
- 到 5 秒仍未恢复时，每隔 **5 秒**继续尝试，直到真实播放、取消本次续播或关闭模式。浏览器拦截时仍会显示手动播放按钮。片尾按同一个暂停截止时间继续下一节，不重播、不再额外等待；按钮暂未出现时每 5 秒重新检查，不会点击弹窗确认或代答测验。
- 可以关闭自动连播或收起面板；开关、等待时间和定时续播模式保存在本机。

5 秒模式允许在后台恢复当前视频及继续下一节；∞ 模式保留原来的前台限制和暂停行为。定时器到期会发起播放请求，实际播放仍取决于网络、播放器和浏览器的自动播放权限。不同课程 ID 均可使用，但需要符合上面的课程学习路径。

## 升级与卸载

升级：下载新版，完整覆盖原安装文件夹中的文件，在扩展管理页点击该扩展的“重新加载”，再刷新课程页。

卸载：在扩展管理页找到“万方课程自动连播”并移除，再刷新课程页。

## 权限与实现

- Manifest V3，仅申请 `storage` 保存设置。
- 脚本匹配 `https://cx.wanfangdata.com.cn/e-training/*`，以支持站内路由；连播面板只在课程学习路径启用。
- 插件本身不发起网络请求，不读取账号令牌。视频权限、课件载入和学习记录由网站自己的逻辑处理。
- `player-bridge.js` 在页面环境订阅现有 Aliplayer 的结束事件，通过 DOM 事件通知隔离脚本。换课使用网站现有的按钮和左侧目录。
- 不主动跳到片尾，不修改学习记录，不自动作答或提交测验。

这是独立工具，与万方或阿里云没有官方关联。网站改版后，播放器或目录定位可能需要更新。

## 开发与测试

仅开发测试需要 **Node.js 24+**：

```sh
npm ci
npm test
```

测试覆盖原生与 SDK 结束通知、重复事件、倒计时与取消、目录与测验状态、播放器重建、主动换课、启动重试、超时及自动播放失败恢复。

默认测试使用 DOM 与播放器替身，不包含第三方播放器 SDK。若另行取得站点同版本的官方 SDK 文件，可指定本机路径，额外运行其原样结束处理逻辑的回归用例：

```sh
ALIPLAYER_SDK_PATH=/path/to/aliplayer-h5-min.js npm test
```

1.2.0 已在 Edge 的真实课程页验证：约 49 秒的导言以 1 倍速从头播放，自然结束后自动进入下一视频并开始播放；“下一视频”按钮也已实际点击验证。后续课件会按网站保存的观看位置续播。

## 更新记录

### 1.4.0

- 统一所有暂停的固定 5 秒计时，移除就绪状态、定位、错误、弹窗和后台过滤。
- 暂停计时独立于换课和启动任务；未恢复时每隔 5 秒重试，直到播放、取消或关闭。
- 后台片尾切换、临时缺失或重建的下一节按钮均可恢复，不再永久停止。
- 增加专门的截止时间唤醒；加载和拖动不重置计时，实际换视频重新计时。

### 1.3.1

- 修复刷新后播放器延迟加载、初始暂停未被检测的问题。
- 修复切换应用后的暂停及 SDK 定位导致的暂停漏检；5 秒模式允许恢复后台的当前视频。
- 修复保存位置接近片尾、没有结束事件时停住的问题；确认位置稳定后继续下一节。
- 新媒体使用新的完整计时，拖动结束后重新计时，取消与播放失败不会触发无限轮询重试。

### 1.3.0

- 新增“定时续播”按钮：∞ 保持原状；5 秒模式在每次暂停后继续播放。
- 新增暂停续播倒计时与“取消本次续播”，支持保存模式。
- 续播与自然结束换课协调，防止重复播放已结束视频或循环重试。

### 1.2.0

- 视频页新增“下一视频”按钮，支持倒计时期间立即主动换课。
- 修复等待视频画面加载后才发起播放可能造成的启动互等。
- 增加播放启动确认、有界重试与独立超时。

### 1.1.1

- 兼容 Aliplayer 自身的结束通知，修复原生 `ended` 未触发时停留原课的问题。

### 1.1.0

- 支持随堂测验提交结果识别、目录导航及手动继续下一视频。
